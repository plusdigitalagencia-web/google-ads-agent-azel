## Onboarding Flow Changes

### Note 1: URL-First Deep Analysis

**Current flow (wrong):**
1. Ask onboarding questions (brand name, product type, goals, etc.)
2. Then analyze the website
3. Fill in brand context

**Better flow:**
1. **First:** Ask for the business URL only
2. **Then:** Do a deep analysis of the website before asking ANY questions:
   - Scrape homepage, about page, FAQ, product pages
   - Extract all product info, pricing, features
   - Pull all customer reviews with exact language
   - Understand their positioning, voice, competitors mentioned
   - Find their social proof (Trustpilot, reviews, endorsements)
   - Map out their product quiz/segmentation if exists
3. **Then:** Ask targeted follow-up questions based on gaps in what you found
4. **Finally:** Create the brand context with real data + user confirmation

**Why this is better:**
- Reduces friction - one question instead of many upfront
- Shows competence - agent demonstrates value immediately
- Better data - pulls real customer language, not user's interpretation
- Targeted questions - only ask what couldn't be found automatically
- Faster onboarding - user doesn't have to type everything out

### Note 2: What to Analyze in Winning Ads

**CRITICAL:** When analyzing ad performance, focus on what actually matters:

1. **Images and Videos are 95% of what matters.** Ad copy is ~5% importance. Never spend time analyzing copy patterns, bullet formats, or text hooks. The creative (visual) is what stops the scroll and drives performance.

   **IMPORTANT CLARIFICATION:** "Ad copy" refers ONLY to the text in the Meta Ads placement UI (primary text, headline, description fields). It does NOT refer to:
   - Text overlays burned into the video/image
   - Words spoken in the video (voiceover, dialogue)
   - On-screen captions or subtitles

   Text within the creative itself IS part of the visual and should be analyzed. Only the Meta placement copy fields are low-priority.

2. **Only analyze high-spend ads.** If an ad has low spend, it means Meta's algorithm doesn't see an opportunity to spend on it. Low spend = algorithm has already decided it's not a winner. Focus exclusively on ads in the upper echelon of spend—those are the ones the algorithm is actively scaling.

**Wrong approach:** Looking at "emerging winners" with high ROAS but low spend
**Right approach:** Analyzing the visuals/videos of top-spending ads to understand what's working

---

### Note 3: NEVER Extract Frames from Videos

**NEVER EVER extract frames from videos for analysis.** This completely destroys the value of video analysis.

Videos work because of:
- Motion and pacing
- Audio and music
- Timing and rhythm
- Transitions
- The full narrative arc

Extracting frames turns a video into meaningless still images. You lose everything that makes video effective.

**If you need to analyze a video, watch the actual video.** There is no shortcut.
