# Static Ad Psychology Checklist

> **Purpose:** Pre-launch quality gate for static ads. Verify every static against this checklist before going live.

---

## Core Principles

### 1. Images Process 60,000x Faster Than Text
- Emotional imagery stops the scroll FIRST
- Copy backs up the message SECOND
- Whatever you want them to feel → put that feeling in the IMAGE, not just copy

### 2. Don't Use Brand Colors
- Especially blue/white on Meta (that's Meta's colors — you blend in)
- Pink mysteriously outperforms across industries (stands out, not common on feed)
- Choose colors that INTERRUPT the scroll

### 3. Copy Density: Go Heavy or Go Light, Never Mid
- **Heavy:** headline, subhead, 2 buttons, bullet list, another button (Pinterest style)
- **Light:** Bold single message
- **Mid:** Doesn't work — commit to one approach

### 4. Message Congruence
- Image and copy must say the SAME thing emotionally
- Brain processes at 11 million bits/second
- If image says one thing and copy says another → scroll
- Example of failure: Copy speaks to "big guys" but image shows slim model = friction

---

## Pre-Launch Checklist

### Emotional Impact
- [ ] Image triggers the target emotion (not just looks nice)
- [ ] Emotion in image matches emotion in copy
- [ ] Would stop MY scroll if I was the target customer

### Visual Design
- [ ] Colors contrast with Meta's blue/white palette
- [ ] No brand colors that blend into the feed
- [ ] Visual hierarchy is clear (what do they see first?)
- [ ] Readable on mobile (not just desktop)

### Copy Quality
- [ ] Headline is specific to cold audience (not vague/warm)
- [ ] Uses customer language, not marketing speak
- [ ] Either copy-heavy OR copy-light — not mid
- [ ] One clear point per static

### Message Alignment
- [ ] Image and headline say the same thing
- [ ] No conflicting messages
- [ ] Target audience would see themselves in this

### Technical
- [ ] Correct dimensions for placement
- [ ] Text under 20% of image area (or tested with higher)
- [ ] File size optimized
- [ ] All text legible at mobile size

---

## Common Failures

### 1. Message Mismatch
**Problem:** Copy says "for big guys" but image shows fit model
**Fix:** Match visual to the exact target audience

### 2. Brand Color Blend
**Problem:** Using blue/white on Meta — invisible
**Fix:** Use contrasting colors (pink, orange, yellow often work)

### 3. Copy-Mid
**Problem:** Some text but not enough to be "heavy"
**Fix:** Either add more (Pinterest style) or reduce to bold single message

### 4. Vague Headlines
**Problem:** "Finally, something that works" (warm audience language)
**Fix:** "For [specific people] who've tried [specific things]" (cold audience language)

### 5. Feature Over Emotion
**Problem:** Image shows product features, not emotional outcome
**Fix:** Show the transformation/feeling, not the product specs

## Quick Reference: Color Psychology

| Color | Association | When to Use |
|-------|-------------|-------------|
| Pink | Stands out, unconventional | Almost always worth testing |
| Orange | Energy, urgency | Sales, limited offers |
| Yellow | Attention, optimism | Happy outcomes |
| Green | Health, money, calm | Wellness, finance |
| Red | Urgency, passion | Use sparingly |
| Blue | Trust (but blends on Meta) | Avoid as primary |
| Black | Premium, serious | Luxury products |

---

## Review Process

1. **Self-review:** Check all boxes above
2. **Peer review:** Have someone else check message congruence
3. **Mobile test:** View at actual mobile size
4. **Scroll test:** Would this stop YOUR scroll?
