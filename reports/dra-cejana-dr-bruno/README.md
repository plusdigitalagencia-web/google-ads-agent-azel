# Dra. Cejana + Dr. Bruno — Relatórios de Campanha

Pasta de relatórios automáticos gerados pelos agentes de análise.

## Estrutura de arquivos
- `meta-report-YYYY-MM-DD.md` — relatório semanal Meta Ads
- `google-report-YYYY-MM-DD.md` — relatório semanal Google Ads

## Como gerar
Abra o Claude Code na pasta do cliente em `Clientes/dra-cejana-dr-bruno/`
e chame o agente correspondente.
