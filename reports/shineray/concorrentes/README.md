# Concorrentes — Shineray Maranhão

Pasta para screenshots de anúncios de concorrentes usados pelo **Agente Meta 01**.

## Formato aceito
Apenas imagens PNG ou JPG — NÃO enviar PDFs.

## Como capturar
1. Abra a Biblioteca de Anúncios da Meta no navegador
2. Tire um print da tela (Command+Shift+4 no Mac)
3. Salve como PNG e faça upload nesta pasta via GitHub

## Nome sugerido para os arquivos
```
YYYY-MM-DD_nome-concorrente.png
```
Exemplos:
- `2026-05-12_honda-motos-brasil.png`
- `2026-05-12_yamaha-motor-brasil.png`
- `2026-05-12_shineray-do-brasil.png`
