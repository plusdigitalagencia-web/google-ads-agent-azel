# Concorrentes — Shineray Maranhão

Pasta para arquivos de inteligência competitiva usados pelo **Agente Meta 01**.

## Como usar

Adicione aqui screenshots, PDFs ou imagens exportadas da Biblioteca de Anúncios da Meta com campanhas ativas de concorrentes. O agente verifica esta pasta automaticamente a cada execução (toda segunda e sexta às 08h).

**Concorrentes prioritários para monitorar:**
- Honda Motos (nacional e MA)
- Yamaha Motor Brasil (nacional e MA)
- Outras concessionárias de motos no Maranhão

## Formato recomendado para os arquivos

Nomeie os arquivos com o padrão:
```
YYYY-MM-DD_concorrente_descricao.pdf
YYYY-MM-DD_concorrente_descricao.png
```

Exemplos:
- `2026-05-12_honda_campanha-whatsapp-maio.pdf`
- `2026-05-12_yamaha_anuncios-ativos-MA.png`

## Como exportar da Biblioteca de Anúncios

1. Acesse: facebook.com/ads/library
2. Busque pelo nome do concorrente ou termo (ex: "moto 0km Maranhão")
3. Tire print ou exporte PDF da página
4. Faça upload deste arquivo nesta pasta via GitHub
